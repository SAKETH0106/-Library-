# 📚 Library

A simple and responsive Library web app built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## 🚀 Live Demo

[View Live Demo](https://sagarpawar-dev.github.io/library/)

## 📖 About

This project is a small Library application where users can add and manage books.

Each book stores information such as:

- Title
- Author
- Number of pages
- Reading status
- Unique ID

The project focuses on practicing JavaScript objects, constructors, prototypes, DOM manipulation, event listeners, and dynamically rendering content on a webpage.

## ✨ Features

- Add new books
- Display books as cards
- Mark books as **Finished** or **To Read**
- Delete books from the library
- Automatically generate a unique ID for every book
- Form validation using HTML `required`
- Responsive layout
- Interactive buttons with hover effects
- Default books displayed when the page loads

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
